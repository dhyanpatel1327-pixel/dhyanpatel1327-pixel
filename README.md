## Featured Projects

**Real-Time ISL Interpreter**
Indian Sign Language recognition system using computer vision
- Built with MediaPipe, OpenCV, and scikit-learn (Random Forest)
- Detects and classifies hand gestures in real time via webcam
- Designed to support communication accessibility for the hearing-impaired community

<br/>

**Air Quality Dashboard**
Real-time AQI monitoring for 10 major Indian cities
- Fetches live data through the OpenWeatherMap API
- Interactive data visualizations built with Matplotlib and Pandas
